# ResourceFinder

Find developer and research resources across APIs, GitHub repositories, videos, books, papers, documents, websites, and tools.

**Live app:** https://resourcefinders.netlify.app/

ResourceFinder is owned by [Perugupalli Saai Abhishikth](https://www.linkedin.com/in/perugupalli-saai-abhishikth-947121222/).

## What is in this repository

This repository contains a reviewed snapshot of the public-facing interface: `index.html`, `styles.css`, `app.js`, `privacy.html`, the logo, and UI icons. The icon licenses and attribution are in `assets/icons/`.

The live app uses a separate backend for search, account verification, and provider integrations. That backend, its API implementation, provider credentials, local configuration, deployment settings, and catalog data are not included here. This frontend snapshot alone will not run the live search service.

Do not commit API keys, access tokens, client secrets, `.env` files, or `config.local.json`. The public site itself can be inspected in any browser, so no browser-delivered code should be treated as secret.
