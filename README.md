# ResourceFinder

Find developer and research resources in one place: APIs, libraries, documentation, videos, books, papers, websites, files, tools, and apps.

**Use the app:** https://resourcefinders.netlify.app/

Search by topic, browse resource types, and use filters to narrow results. Signed-in users can keep bookmarks and collections in their browser. Resource links lead to their original publishers; check each publisher's current pricing, terms, and license before use.
