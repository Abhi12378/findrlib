# FindrLib

<img src="assets/findrlib-icon.png" alt="FindrLib logo" width="96">

Find developer and research resources across APIs, GitHub repositories, videos, books, papers, documents, websites, and tools.

**Live app:** https://resourcefinders.netlify.app/

FindrLib is owned by [Perugupalli Saai Abhishikth](https://www.linkedin.com/in/perugupalli-saai-abhishikth-947121222/).

## What is in this repository

This is the public frontend snapshot: `index.html`, `styles.css`, `app.js`, `privacy.html`, supplied FindrLib artwork, and attributed UI icons. The live search, Google token verification, provider integrations, catalogs, deployment configuration, and credentials are maintained separately. This snapshot alone does not run the search service.

No API keys, access tokens, client secrets, `.env` files, or `config.local.json` belong in this repository. Browser-delivered code is public by design.
